# SonicTag Studio 🎵

一个轻量、优雅的本地音频标签与歌词自动匹配工具。基于 FastAPI + Mutagen 构建，配合 Liquid Glass 液态玻璃质感的现代 Web 界面。

> 自动识别歌曲信息、匹配高清封面与 LRC 歌词，一键写入 FLAC / MP3 标签。

---

## ✨ 效果预览

- **Liquid Glass 界面**：顶部栏、侧边栏、偏好条等面板采用悬浮液态玻璃材质，支持动态流光背景
- **沉浸歌词视图**：全屏流光 + 大封面 + 同步滚动歌词
- **智能播放预览**：内置音频播放器，支持波形进度条、画中画歌词、播放队列

---

## 🚀 核心功能

| 功能 | 说明 |
|------|------|
| **智能元数据匹配** | 基于 iTunes 全球曲库检索，自动提取歌名、艺术家、专辑、流派、年份、曲目编号、高清封面（最高 1400×1400） |
| **多版本候选** | 自动展示多个候选版本（单曲/专辑/不同地区），点击即可切换 |
| **LRC 同步歌词** | 聚合网易云音乐 + LRCLIB 双语歌词，按时间戳自动对齐合并 |
| **批量打标** | 拖入多首 FLAC / MP3，自动队列识别，一键写入标签 |
| **独立 .lrc 导出** | 除了嵌入音频文件，还可导出同名 `.lrc` 歌词文件 |
| **本地直存** | 原生文件夹选择，记住输出路径，直接保存到本地目录 |
| **车载兼容模式** | 可选压缩封面尺寸，适配车机播放器 |
| **音频播放预览** | 内置播放器，支持播放/暂停、上一首/下一首、循环/随机、倍速、音量、波形进度条 |
| **沉浸模式** | 手动进入沉浸视图，隐藏非必要 UI，专注歌词与封面 |
| **主题适配** | 自动跟随系统浅色/深色模式，支持手动切换 |

## 📦 安装与运行

### 环境要求

- Python 3.10+
- Windows / macOS / Linux（本地文件夹选择功能目前依赖 tkinter）

### 1. 克隆仓库

```bash
git clone https://github.com/yourname/sonictag-studio.git
cd sonictag-studio
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动服务

```bash
python app.py
```

程序会自动在浏览器打开 `http://127.0.0.1:8000`。

---

## 🎹 使用指南

1. **导入音频**：拖拽 FLAC / MP3 文件到侧边栏，或点击侧边栏底部区域选择文件
2. **自动匹配**：程序会自动搜索元数据、封面和歌词
3. **核对与修正**：在标签编辑视图中查看/修改歌曲信息，切换候选版本
4. **预览**：点击播放按钮试听，查看波形进度与同步歌词
5. **导出**：选择保存模式（本地目录或 ZIP 下载），点击「一键导出」

### 归档规则

支持自定义文件保存路径：

- `{artist}/{album}/{track} - {title}`
- `{artist} - {title}`
- `original`（保持原文件名，加 `[Tagged]_` 前缀）

## 🛠 技术栈

- **后端**：FastAPI、Uvicorn、Mutagen、Requests
- **前端**：原生 HTML / CSS / JavaScript（无框架依赖）
- **数据源**：iTunes Search API、网易云音乐 API、LRCLIB
- **设计**：Liquid Glass 液态玻璃、动态流光、Apple Music 风格布局
