SonicTag Studio 🎵
高颜值、本地运行的现代化音乐标签自动匹配、双语歌词合成与音乐库整理工坊。

基于 FastAPI + Mutagen + Web Audio 构建，融汇 macOS 质感磨砂亚克力设计与发烧级音频工具箱。

✨ 核心特性
1. 🎨 极致 Apple 设计美学与三维视界
三大原生视界自由切换：

🏷️ 标签编辑视界 (Tag Editor)：聚焦元数据精准校对，支持多候选版本横滚选择、自定义封面拖拽与唱片级音轨排版。

🎤 沉浸歌词视界 (Immersive Lyrics)：Apple Music 极简大字双语排版，正在演唱的歌词高亮放大，未演唱句子智能虚化，支持点击任意歌词秒级跳转试听。

💿 唱片画幅视界 (Vinyl & Visualizer)：拟物黑胶唱片随音乐播放平滑旋转；内置 Web Audio API 驱动的实时声学动态频谱波形与母带规格展台。

深浅色主题自适应：自动跟随系统/浏览器 Dark/Light Mode 切换，亦可手动一键固定。

macOS 侧边栏抽屉折叠：一键折叠左侧待处理队列，右侧工作画幅自动平滑舒展为全屏空间，状态持久化记忆。

无干扰视口约束：彻底去除原生粗笨白色滚动条，多版本候选栏支持滚轮横向顺滑滑动。

2. 🈳 外语歌曲双语 / 翻译歌词智能合成
毫秒级高容差时间戳对齐：独家 merge_bilingual_lrc 算法，将外语原文歌词与中文翻译歌词自动毫秒级对齐，生成国际通用的双行同戳标准 LRC 文件。

三模一键自由切换：自动探测歌曲是否具备翻译，动态提供 [ 双语 ] [ 原文 ] [ 译文 ] 三合一视窗与导出选项。

独立同名 .lrc 文件导出：打标同时可自动输出同名独立 .lrc 歌词文件，完美适配车载、Walkman 与各类便携播放器。

3. 🎼 Hi-Res 硬件级音质参数透视
底层编码硬件透视：导入音频文件即刻解析真实采样率（Sample Rate）、量化位深（Bit Depth）、平均码率（Bitrate）与声道数。

发烧级质感徽标：

✦ Hi-Res Lossless：≥ 24-bit / 96kHz 无损母带（黑金高亮）

● Lossless：16-bit / 44.1kHz CD 级无损（金属银标）

MP3：320 kbps 高品质立体声

4. 🌐 全球音源库并发检索与多候选自选
免手动切区：后台并发智能聚合全球曲库（US 全球库 + CN 国区并发查询并自动去重），欧美热单、华语流行、J-Pop、K-Pop 均可一次性命中。

高清封面提取：自动拉取高达 1400×1400 的官方高规格专辑封面。

自定义封面拖拽覆盖：支持将本地任意图片直接拖入封面视窗一键替换。

5. 📁 唱片级完备元数据与音乐库智能归档整理
专业级字段写入：全面补齐 音轨号（Track Number / Total Tracks）、光盘碟号（Disc Number / Total Discs） 及 专辑艺术家（Album Artist），导入播放器严格按 CD 官方曲序播放，告别首字母乱序。

智能文件归档重命名（Library Organizer）：

📁 {歌手}/{专辑}/{音轨} - {歌名}.flac（自动根据元数据在目标目录建立层级文件夹）

📄 {歌手} - {歌名}.flac（平铺规范化单曲名）

保持原始文件名

🚗 车载车机兼容模式：自动调用 PIL 将过大分辨率封面图优化压缩至标准兼容尺寸，杜绝车机或砖机因封面体积超标卡顿黑屏。

6. ⚡ 本地免解压直存与实时进度追踪
原生文件夹直存：支持调用 Windows 原生目录选择器，可设定持久化默认音乐库路径，点击导出静默写入并自动唤起资源管理器定位。

实时进度浮层（Modal Sheet）：双阶段追踪数据缓冲与逐首写入进度（当前处理文件名、百分比及打包状态）。
