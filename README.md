# SonicTag Studio 🎵

一个轻量、优雅的本地音频标签与歌词自动匹配写入工具。基于 FastAPI、Mutagen 构建，配合 Apple 质感的现代磨砂毛玻璃 Web 界面。

## ✨ 特性

- **智能多音源聚合**：并发检索全球曲库（iTunes API），精准提取高清专辑封面（高达 1400x1400）、流派、曲名、专辑与发行年份。
- **精准 LRC 滚动歌词**：基于 LRCLIB 接口比对歌曲名、艺术家与音频时长，精准拉取时间戳同步歌词。
- **多版本自主候选**：自动呈现多个候选版本（单曲/专辑版/不同年份），点击即可实时切换。
- **批量处理**：支持拖入多首 FLAC / MP3 文件自动队列识别与一键打标。
- **独立 .lrc 歌词导出**：除了嵌入音频文件，还支持自动导出同名独立 `.lrc` 文件。
- **本地直存**：支持原生文件夹选择，可记住输出路径，免去浏览器重复下载与解压。
- **自适应设计**：Apple 磨砂亚克力设计风格，自适应系统浅色/深色主题，视口自适应防溢出。
